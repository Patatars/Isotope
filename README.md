# Isotope: Multiplayer FPS & Gauss Splatting

## About
**Isotope** is a multiplayer First-Person Shooter developed in **Unreal Engine 5**. This project is being developed as a student project at **FMFI UK**.

The project focuses on correct network architecture (Dedicated Server + Client), replication, and gameplay logic. The next phase (Summer Semester) will involve integrating **3D Gauss Splatting** technology for realistic environment rendering.

## Key Features
*   **Engine:** Unreal Engine 5 (Custom source build for Server targets).
*   **Networking:** Fully replicated Dedicated Server architecture.
*   **Gameplay:** Team deathmatch mechanics and new gamemodes, weapon handling, score system.
*   **Tech Stack:** C++, Blueprints.
